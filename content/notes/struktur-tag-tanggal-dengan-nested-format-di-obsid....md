# Struktur Tag Tanggal Dengan Nested Format Di Obsidian

Saya menggunakan format tag tanggal seperti `#2025/04/08` dengan *backslash* (`/`) sebagai pemisah antara tahun, bulan, dan hari. Format ini memanfaatkan fitur *nested tag* di Obsidian, sehingga memudahkan pencarian berdasarkan kriteria spesifik—tahun saja, bulan saja, atau kombinasi tertentu.
Contoh: Untuk mencari catatan dengan tag tahun **2025** dan bulan **April**, saya cukup mengetik `#2025/04` di pencarian. Hasilnya otomatis terfilter tanpa perlu sintaks kompleks.

Dengan pendekatan ini, organisasi dan *retrieval* catatan menjadi lebih efisien.
